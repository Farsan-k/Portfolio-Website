## 🚀 Getting Started

Want to run the portfolio locally?

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Farsan-k/Portfolio-Website.git
```

### 2️⃣ Navigate to the Project

```bash
cd Portfolio-Website
```

### 3️⃣ Run the Website

Since this is a frontend portfolio website, you can simply open:

```text
index.html
```

in your browser.

For a better development experience, you can also use the **Live Server** extension in VS Code.
